# JSX Direct Binding

The RFSG JSX runtime accepts signals in host element properties. These bindings attach to the DOM element and update without asking the component to render again.

Try the direct-bound color and form field in [Interactive Examples](./examples).

```tsx
<input bindValue={name} />
<button title={status} style={{ color }} />
```

Direct binding requires the RFSG JSX runtime (`jsxImportSource: 'react-fine-grained-signals'`) in the relevant client build. See the [JSX binding guide](https://github.com/sakzw/react-fine-grained-signals/blob/main/docs/guides/jsx-bindings.md).
