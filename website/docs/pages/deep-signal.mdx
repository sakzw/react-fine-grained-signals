# Deep Signal / Collections

`deepSignal` creates a reactive proxy for nested object properties, arrays, and supported collections. Read or write the properties you need directly.

Try a nested object and list in [Interactive Examples](./examples).

`For` keeps item identity while mapping a reactive collection; `Index` associates each position with a signal. Choose the helper that matches whether your UI follows item identity or array position.

See the [control-flow guide](https://github.com/sakzw/react-fine-grained-signals/blob/main/docs/guides/control-flow.md).
