# Core Signals

`signal(value)` creates writable state. `computed(fn)` derives a cached value from signals read by `fn`; `effect(fn)` runs a side effect when those dependencies change.

Try the runnable computed value in [Interactive Examples](./examples).

```tsx
const first = signal(2)
const doubled = computed(() => first.value * 2)
```

The canonical primitive guide is [docs/guides/core-primitives.md](https://github.com/sakzw/react-fine-grained-signals/blob/main/docs/guides/core-primitives.md).
