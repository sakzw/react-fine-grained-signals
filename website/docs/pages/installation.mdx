# Installation

RFSG targets React 19. Install the runtime, then add the optional transform only if you want automatic tracking of signal reads inside components.

```sh
pnpm add react-fine-grained-signals
pnpm add -D unplugin-react-fine-grained-signals
```

The transform package supports Vite and other bundlers through unplugin. The runtime also works without a transform when using hooks or explicit JSX bindings.

## Repository development

Before v0.3.0 is published, from the repository root run `node website/scripts/prepare-repository.mjs`, then `pnpm --dir website install`. This packs the current runtime and unplugin into ignored `.repo-packages/` tarballs. Subsequent site commands run from `website/`; dependencies resolve from local packages without a workspace link or source copy.

## Standalone site

After publication, replace the two `file:.repo-packages/...` entries in this directory's `package.json` with the corresponding npm versions, regenerate this directory's `pnpm-lock.yaml`, and remove the prepare step. No site source imports depend on the monorepo layout.
