# React Fine-Grained Signals

Fine-grained signal rendering for React 19. Keep React's component model while updating the DOM nodes that read a signal.

[Get started →](./installation)

## Why signals with React?

Signals hold mutable values and notify only their consumers. RFSG connects those reads to React's lifecycle and JSX, so local state can update a text node or host property without rerendering its parent component.

See [Interactive Examples](./examples) for runnable demos of the runtime and transform.

## Features

- Signals, computed values, effects, and collection helpers.
- React hooks for component-local and tracked state.
- Optional Managed Transform for automatic render read tracking.
- JSX direct bindings for attributes, styles, and form values.
