# Deep Signal & Collections

```ts
deepSignal<T extends object>(initialValue: T): DeepSignal<T>
```

`deepSignal` tracks plain objects and arrays property by property. Changing one property re-renders only the readers of that
property.

```ts
import { computed, deepSignal } from 'react-fine-grained-signals'

const state = deepSignal({
  user: { profile: { name: 'Alice' } },
  items: ['first'],
})
const name = computed(() => state.value.user.profile.name)

state.value.user.profile.name = 'Bob'
state.value.items.push('second')
```

## Rules

- Read and write through `state.value`. `state.peek()` is an untracked,
  read-only snapshot typed `DeepReadonly<T>`: writing through it is a compile
  error. Change state through `state.value`.
- Assignment, deletion, and the standard array mutations are observable.
- Nested plain objects and arrays are reactive. Class instances, functions,
  `Date`, promises, existing signals, and nested `Map`, `Set`, `WeakMap`, and
  `WeakSet` values are opaque: the signal notifies only when the property
  holding one is replaced. Use `deepCollectionSignal` to track their contents.
- Accessor properties, frozen or sealed objects, and non-extensible objects are
  rejected instead of being made partly reactive.
- A `deepSignal` cannot be a JSX signal child or bound prop; read it inside a
  tracked component, or select a primitive with `useDeepSignalValue`.

## Collections

`deepCollectionSignal` also tracks `Map`, `Set`, `WeakMap`, and `WeakSet`,
including as the root. It is a separate function so an app using only plain
objects and arrays does not load the collection support (about 3 kB gzip
smaller):

```ts
const state = deepCollectionSignal(new Map<string, { count: number }>())
state.value.set('item', { count: 1 })
```

A single plain object or array cannot be shared between a `deepSignal` and a
`deepCollectionSignal`; that throws. In React, use `useDeepCollectionSignal`;
`useDeepSignalValue` accepts both kinds.

- `Map` `get` and `has` track per key; `size`, key iteration, and entry
  iteration are tracked separately.
- `Set` `has`, `size`, and iteration are tracked separately.
- Weak collections track key operations only.
- Plain objects and arrays stored as keys, members, or values come back as deep
  proxies.

:::warning
v0.4 moved collection tracking from `deepSignal` to `deepCollectionSignal`. If
you put a `Map` or `Set` in a `deepSignal` in v0.3, switch to
`deepCollectionSignal`.
:::
