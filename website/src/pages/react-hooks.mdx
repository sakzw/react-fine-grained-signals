# React Hooks

```tsx
import { useComputed, useSignal, useSignalEffect, useSignalTracking } from 'react-fine-grained-signals'

function Counter({ step }: { step: number }) {
  useSignalTracking()
  const count = useSignal(0)
  const scaled = useComputed(() => count.value * step, [step])

  useSignalEffect(() => {
    console.log('count:', count.value)
  })

  return <button onClick={() => (count.value += step)}>{scaled.value}</button>
}
```

## useSignal

```ts
useSignal<T>(initialValue: T): FormBindableSignal<T>
```

Keeps one signal for the component lifetime. `initialValue` is used on the
first render only. Reading `.value` during render needs a tracking boundary in
that same component: `useSignalTracking()` or the
[managed transform](/managed-transform).

## useDeepSignal

```ts
useDeepSignal<T extends object>(initialValue: T | (() => T)): DeepSignal<T>
```

Keeps one [deep signal](/deep-signal). Pass a factory for an expensive initial
value.

## useComputed

```ts
useComputed<T>(getValue: () => T, dependencies?: DependencyList): ReadonlySignal<T>
useComputed<T>(options: { get: () => T; set: (value: T) => void }, dependencies?: DependencyList): FormBindableSignal<T>
```

A computed whose identity stays stable while its dependency array is unchanged.

- **Without a dependency array**, the getter must read only signals; its computed
  identity stays stable across ordinary renders.
- Fast Refresh may recreate this memoized computed after an edit, applying the
  edited getter/setter while preserving React component state. This is
  development behavior; production identity remains stable across ordinary
  renders.
- **With a dependency array**, list every non-signal value the getter captures:
  `useComputed(() => count.value * step, [step])`.
- Keep the omitted/explicit mode and explicit array length and order fixed. A
  mode or length change throws before a stale memoized computed can be reused.
- Keep getter-only versus writable capability fixed at the same Hook call site.
  Switching between those overloads throws; changing dependency values at the
  same positions is supported.

## useSignalEffect

```ts
useSignalEffect(callback: () => void | (() => void), dependencies?: DependencyList): void
```

Starts an effect after commit and disposes it on unmount, Strict Mode replay
included. For this hook, omitted dependencies and `[]` are equivalent: both
retain the initial callback and can be switched between. This differs from
React `useEffect` without a dependency list, which runs after every commit.
List captured props/state in a dependency array; changing values at the same
positions cleans up and reconnects the effect. Keep its length and order fixed:
a length change, including empty/non-empty, throws instead of retaining a stale
callback after React's warning.

## useSignalTracking

```ts
useSignalTracking(): void
```

Opens the render-tracking window. Call it once, unconditionally, as the first
Hook in every component that reads `.value` while rendering — or let the build
plugin handle it.

The window is best-effort: it closes at the next `useSignalTracking()` call,
when React starts committing, or in a microtask. Every reading component needs
its own call; the window is not inherited from a parent.

## useSignalValue and useDeepSignalValue

```ts
useSignalValue<T>(source: ReadonlySignal<T>): T
useDeepSignalValue<T extends object, S>(source: DeepSignal<T>, selector: (value: T) => S, dependencies?: DependencyList): S
```

Explicit single subscriptions, for when you want one named subscription instead
of a component-wide window. `useDeepSignalValue` selects one primitive from deep
state. Omitting dependencies retains the initial selector closure and is for
selectors that read only signal state; it does not track props automatically.
Use `[]` for an explicit empty dependency array, or pass every captured
non-signal value such as `[prefix]`. Keep the chosen mode and explicit array
length stable for the lifetime of the component.

```tsx
const name = useDeepSignalValue(state, (value) => value.user.name);
const label = useDeepSignalValue(
  state,
  (value) => `${prefix}: ${value.user.name}`,
  [prefix],
);
```

## Control flow

`react-fine-grained-signals/utils` provides `Show`, `Switch`/`Match`,
`For`, and `Index`. Each one forms its own reactive boundary when given a
signal, so an update re-renders the utility and not its parent. See the
[For / Index example](/examples#for-and-index).

The complete reference is [React hooks](https://github.com/sakzw/react-fine-grained-signals/blob/main/docs/guides/hooks.md) and
[JSX control-flow utilities](https://github.com/sakzw/react-fine-grained-signals/blob/main/docs/guides/control-flow.md).
