# Installation

```bash
pnpm add react-fine-grained-signals
```

React 19.3 or newer is a peer dependency. The package is ESM-only and publishes
its entry points and types through `exports`, so TypeScript needs
`moduleResolution` set to `bundler`, `node16`, or `nodenext` to resolve
`react-fine-grained-signals/utils` and the JSX runtime.

:::info
This site documents the v0.4 line. Upgrading from v0.3? Read the
[v0.4 migration guide](https://github.com/sakzw/react-fine-grained-signals/blob/main/docs/migration/v0.4.md).
:::

## Entry points

| Import | Contents |
| --- | --- |
| `react-fine-grained-signals` | Core primitives, React hooks, `isSignal` |
| `react-fine-grained-signals/utils` | `Show`, `Switch`, `Match`, `For`, `Index` |
| `react-fine-grained-signals/jsx` | Full JSX: classic `createElement` and `Fragment` fallback |
| `react-fine-grained-signals/jsx/jsx-runtime` | The Full JSX runtime for direct DOM bindings |
| `react-fine-grained-signals/jsx/jsx-dev-runtime` | Development JSX entry for Full |
| `react-fine-grained-signals/jsx/lite` | Lite JSX: classic `createElement` and `Fragment` fallback |
| `react-fine-grained-signals/jsx/lite/jsx-runtime` | The Lite runtime for Signal children only |
| `react-fine-grained-signals/jsx/lite/jsx-dev-runtime` | Development JSX entry for Lite |
| `react-fine-grained-signals/internal` | Used by the build plugin's generated code. Not public API and outside semver |

## Optional: the build plugin

The hooks work without any build configuration. To have components subscribe
automatically, add the plugin:

```bash
pnpm add -D unplugin-react-fine-grained-signals
```

Use matching `0.4.x` versions of the plugin and the runtime. The plugin needs
Node.js `^22.18.0` or `>=24.11.0`.

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import signals from 'unplugin-react-fine-grained-signals/vite'

export default defineConfig({
  plugins: [signals({ mode: 'auto' })],
})
```

The same package provides `/rollup`, `/webpack`, `/rspack`, and `/esbuild`
entry points. See [Managed Transform](/managed-transform).

## Optional: the JSX runtime

Choose the runtime per file with a pragma at the top of that file:

Full supports Signal children and the documented direct host bindings:

```tsx
/** @jsxImportSource react-fine-grained-signals/jsx */
```

Use `react-fine-grained-signals/jsx/lite` instead when Signal children are the only
direct binding needed. Lite does not support Signal-valued host attributes,
style bindings, `bindValue`, or `bindChecked`. Both runtimes are explicit
opt-ins; React JSX remains in use when `jsxImportSource` is not set.

```tsx
/** @jsxImportSource react-fine-grained-signals/jsx/lite */
```

To select Full for the whole project, set `jsxImportSource` in `tsconfig.json`:

```json [tsconfig.json]
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "react-fine-grained-signals/jsx"
  }
}
```

Set `jsxImportSource` to `react-fine-grained-signals/jsx/lite` for a project-wide
Lite runtime instead.

See [JSX Direct Binding](/jsx-direct-binding).
