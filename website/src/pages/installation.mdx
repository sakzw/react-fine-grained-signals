# Installation

```bash
pnpm add react-fine-grained-signals@0.2.1
```

React 19 or newer is a peer dependency. The package is ESM-only and publishes
its entry points and types through `exports`, so TypeScript needs
`moduleResolution` set to `bundler`, `node16`, or `nodenext` to resolve
`react-fine-grained-signals/utils` and the JSX runtime.

:::warning
This site documents the repository's unreleased v0.3.0 source. As checked on
October 19, 2026, npm publishes v0.2.1 for both the runtime and build plugin.
The command above installs v0.2.1, not the APIs shown on this site. Wait for the
v0.3.0 release before using these APIs from npm. Upgrading from v0.2.1? Read the
[v0.3 migration guide](https://github.com/sakzw/react-fine-grained-signals/blob/main/docs/migration/v0.3.md).
:::

## Entry points

| Import | Contents |
| --- | --- |
| `react-fine-grained-signals` | Core primitives, React hooks, `isSignal` |
| `react-fine-grained-signals/utils` | `Show`, `Switch`, `Match`, `For`, `Index` |
| `react-fine-grained-signals/jsx-runtime` | The opt-in JSX runtime for direct DOM bindings |
| `react-fine-grained-signals/lite` | Classic JSX fallback for the Lite runtime |
| `react-fine-grained-signals/lite/jsx-runtime` | The opt-in Lite runtime for Signal children only |
| `react-fine-grained-signals/lite/jsx-dev-runtime` | Development JSX entry for Lite |
| `react-fine-grained-signals/jsx-dev-runtime` | Development JSX entry for Full |
| `react-fine-grained-signals/runtime` | Low-level boundaries used by the build plugin (`useSignalCapture`, `useManagedSignals`) |

## Optional: the build plugin

The hooks work without any build configuration. To have components subscribe
automatically, add the plugin:

```bash
pnpm add -D unplugin-react-fine-grained-signals@0.2.1
```

The currently published v0.2.1 plugin is for the v0.2.1 runtime. Use matching
`0.3.x` versions only after both v0.3.0 packages are published.

```ts [vite.config.ts]
import { defineConfig } from 'vite'
import signals from 'unplugin-react-fine-grained-signals/vite'

export default defineConfig({
  plugins: [signals({ mode: 'auto' })],
})
```

The same package provides `/rollup`, `/webpack`, `/rspack`, and `/esbuild`
entry points. See [Managed Transform](/managed-transform).

## Optional: the JSX runtime

Opt one file in with a pragma on its first line:

```tsx
/** @jsxImportSource react-fine-grained-signals */
```

Choose `react-fine-grained-signals/lite` instead when Signal children are the
only direct binding needed. Lite does not support Signal-valued host
attributes, style bindings, `bindValue`, or `bindChecked`. Full and Lite are
both explicit opt-ins; React JSX remains in use when `jsxImportSource` is not
set. See [JSX Direct Binding](/jsx-direct-binding) for support and bundle
trade-offs.

or the whole project through `tsconfig.json`:

```json [tsconfig.json]
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "react-fine-grained-signals"
  }
}
```

See [JSX Direct Binding](/jsx-direct-binding).
