# v0.3への移行

## `deepSignal`のリアクティブcollection

既存の`deepSignal(value)`の動作は変わりません。nested `Map`と`Set`はProxyから直接取得した場合にread-only viewを維持し、それ以外のcollectionは不透明なままです。既存コードの移行は不要です。

`Map`、`Set`、`WeakMap`、`WeakSet`のentryをリアクティブにする場合は、新しいoptionを渡します。

```ts
const state = deepSignal(new Map<string, { count: number }>(), {
  collections: "reactive",
});
```

collection rootと、plain objectまたは配列にnestedされたcollectionに対応します。dependencyの追跡と通知には`state.value`経由で読み書きしてください。元のcollectionや`.peek()`から変更すると通知は発生しません。

リアクティブcollection modeは同一realmの組み込みcollectionに対応します。Weak collectionは列挙できません。method呼び出し時にkeyを正規化し、non-registered symbol keyはnative runtimeが対応している場合に使えます。dependencyとidentityの詳細は[Core primitives](../guides/core-primitives.ja.md#リアクティブcollectionopt-in)を参照してください。
